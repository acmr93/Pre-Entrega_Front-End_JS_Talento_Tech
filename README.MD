#Pre-entrega para Front-End JS

Esta pagina fue realizada con el fin de compartir el progreso obtenido en la primera etapa del curso Front-End JS de Talento Tech.

Requerimientos de la pre-entrega:

Una pagina web con estructura
Tener una estrucutra báica de HTML (header, nav, main, section, footer).
Crear un README.md explicando el proposito de la pagina.
Tener un fomulario de contacto utilizando Formspree.
Tener un archivo CSS y que contemple lo siguiente:
    Aplicar estilos basicos con CSS header, footer y lista de navegación.
    Usar fuentes de Google Fonts
    Background en algunas secciones de la pagina.
Diseño Responsivos:
    Flex aplicado a la sección de Productos
    Grid aplicado a la sección de Reseñas
    Media Queries a la sección de Contacto
Contenido Multimedia y Navegacion:
    Incluir Imagenes o videos.
    Lista de navegacion que simule una navegacion interna.
Subir el proyecto
    Utilizar un hosting gratuito.
    Repositorio publico en Github.
